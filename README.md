# 📊 Customer Behaviour Analysis Dashboard

## 📌 Project Overview

The **Customer Behaviour Analysis Dashboard** is an end-to-end data analytics project focused on understanding customer purchasing patterns, identifying customer segments, and generating meaningful business insights.

The project uses Python (Pandas) for data cleaning and analysis, SQL for querying and extracting insights, and Power BI for developing interactive dashboards and visualizations.

## 🎯 Project Objectives

- Analyze customer purchasing behaviour and transaction patterns.
- Identify customer segments based on purchasing activities.
- Understand customer purchasing trends.
- Track important business metrics using KPIs.
- Generate actionable insights to support business decisions.

## 🔍 Project Workflow

1. **Data Collection:** Collected customer-related data for analysis.
2. **Data Cleaning:** Handled missing values, duplicate records, and inconsistencies using Python and Pandas.
3. **Data Analysis:** Explored customer purchasing patterns and extracted insights.
4. **Customer Segmentation:** Analyzed customer groups based on purchasing behaviour.
5. **Data Visualization:** Developed interactive dashboards using Power BI.
6. **Business Insights:** Identified trends to support data-driven decisions.
